# Attribution for the flashcard data

The generated flashcard bank combines and modifies the following open data:

- Dictionary definitions, Vietnamese senses and IPA source data: **Từ điển
  Anh–Việt thichhoc.com (thichhoc-dict)**, licensed under CC BY-SA 4.0.
  <https://github.com/thichhoc-org/thichhoc-dict>
- Original sources named by that project: WordNet 3.1 (Princeton), CMUdict
  (Carnegie Mellon University), Wiktionary and wordfreq.
- Bilingual examples: **Tatoeba**, redistributed by ManyThings, licensed under
  CC BY 2.0 France. <https://tatoeba.org/> and
  <https://www.manythings.org/anki/>

The source data was selected, normalized, mapped to CEFR seed entries and mixed
with generated fallback examples. It has therefore been modified. The derived
dictionary data is distributed under CC BY-SA 4.0. Generated records remain in
`draft` status until a qualified editor reviews them.
